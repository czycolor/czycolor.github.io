Privacy Policy — ForChina Uploader

Effective date: 2026-10-23 · Last updated: 2026-10-23

1. Overview

ForChina Uploader is a private, personal-use desktop application operated by the owner of the YouTube channel ForChina (@forchina-j7m). Its sole function is to upload and manage videos on that own channel using the official YouTube Data API v3. The application is not distributed to, and not intended for, any other user.

2. Data we access and store

  • Google account access: The application requests the OAuth scope youtube.upload (plus basic channel identification) for the owner's own Google account only.
  • Credentials: The OAuth refresh token is stored locally on the owner's own computer, in the application's working directory. It is transmitted only to Google's OAuth servers. It is never sent to any other server, and we operate no backend of any kind.
  • Content data: Video files, titles, descriptions and subtitles are supplied by the owner and sent directly from the owner's computer to YouTube. No copy is kept by the application beyond the original local files.

We do not collect, use, share or sell any other user data. There is no analytics, no advertising, no cookies and no third-party tracking in the application or on this website.

3. Data sharing

No data is shared with, or sold to, any third party. The only external service involved is Google's own YouTube API.

4. Data retention and deletion

OAuth credentials are retained only until the owner revokes access. Revocation is immediate and can be done at any time on the Google account permissions page (remove "ForChina Uploader"), after which the locally stored token file is deleted. All uploaded videos remain under the owner's exclusive control on YouTube and can be deleted there at any time.

5. Google API Services User Data Policy

This application's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. For information on how Google handles user data, see Google's Privacy Policy and the YouTube Terms of Service.

6. Contact

This is a single-operator personal project. For any question about this policy, contact the operator via the GitHub repository hosting this page: github.com/czycolor/czycolor.github.io.
